1. Welcome to SMILE

SMILE is a beginner-first programming language. Its name—Simple Modern and Intuitive Language for Everyone—is a promise: the language stays small enough to understand while teaching real ideas such as types, functions, recursion, and arrays.

Your first program
Print "Hello, world!"

Output:

Hello, world!

2. The learning mission

You write one SMILE program. The compiler can show the same idea in ten destinations. A loop is still a loop and a function is still a function, but you learn how each community normally writes it.

Read

Start with short, case-insensitive BASIC-like source.

Compare

Open C#, JavaScript (Node.js), Python, COBOL, or another target pane.

Experiment

Change the source and watch every generated program change.

Generated code is teaching material. SMILE prefers ordinary destination constructs over a hidden runtime.

3. The compilation journey

The lexer recognizes words and symbols. The parser checks their arrangement. The binder connects names to typed declarations. The evaluator can run the bound meaning, while a generator translates it.

4. Desktop and command line

Desktop

Open a .smile file, choose a target in a pane, then use Build & Run when that toolchain is installed. Work happens asynchronously, so the editor stays responsive.

CLI

dotnet run --project src\SMILE.Cli -- examples\core-basic-2-canonical.smile --target python --run
dotnet run --project src\SMILE.Cli -- examples\core-basic-2-canonical.smile --target all

The stable target ID for JavaScript (Node.js) is javascript. Diagnostics include a code, line, column, and a plain-language message.

5. Source layout, comments, and names

Statements normally end at a newline. Keywords and identifiers ignore case, so Score and score are the same name. An apostrophe starts a comment.

Smallest example

' A full-line comment
Score = 10  ' An end-of-line comment
Print score

Output: 10

Common mistake

// not a SMILE comment

Use an apostrophe instead. Alternate comment markers are rejected.

Pattern: identifier = expression. A name begins with a Unicode letter or underscore and continues with letters, decimal digits, or underscores.

7. Variables, Dim, and Const

Pattern: Name = expression, Dim Name As Type, or Const Name = constant-expression.

Const Bonus = 5
Dim Score As Number
Name = "Sin"
Score = 10 + Bonus
Print Name; ": "; Score

First assignment can create a variable when Option Explicit is absent. Dim creates typed default storage. Const is compile-time and immutable.

Common mistake: assigning Bonus = 6. Constants cannot change. Put changing data in a variable declared by Dim.
Back to top

8. Option Explicit

Pattern: Option Explicit once, as the first nonblank, noncomment item. It turns misspelled or undeclared variable names into errors.

Option Explicit
Dim Score As Number
Score = 100
Print Score
Common mistake: writing Scroe = 100 without a declaration. Correct the spelling or add the intended Dim. The directive produces no runtime code.

9. Arithmetic and precedence

Unary -; then * / Mod; then + -; then comparisons; then And; then Or. Parentheses make intent explicit. Division truncates toward zero.

Print 2 + 3 * 4
Print (2 + 3) * 4
Print -7 / 2
Print -7 Mod 2
14
20
-3
-1
Common mistake: expecting a decimal answer from 7 / 2. Number is a whole-number type; the result is 3.

10. Text and concatenation

Pattern: TextExpression + TextExpression. A doubled quote inside a literal becomes one quote.

First = "Simple"
Last = "Environment"
Print First + " Modern Interactive Learning " + Last
Print "She said ""Hi""."
Common mistake: "Score=" + 10. Types are exact. Print unlike types as separate expressions: Print "Score="; 10.
Back to top

11. Comparisons and Boolean logic

Number supports ordering. Like-typed values support = and <>. Not, And, and Or work on Boolean. And/Or short-circuit.

Age = 14
HasPermission = True
CanEnter = Age >= 13 And HasPermission
Print CanEnter

Output: True.

Common mistake: If Score Then. A Number is not a condition. Write If Score > 0 Then.
Back to top

12. Print

Pattern: Print [expression {; expression} [;]]. Print inserts no spaces. A trailing semicolon keeps the cursor on the same line.

Print "A"; 1; True
Print "loading";
Print "."
Print
A1True
loading.
Common mistake: Print Hello prints the variable Hello. For literal text, write Print "Hello".

13. If / Else If / Else

The first true clause runs. Else is the fallback.

Score = 87
If Score >= 90 Then
    Grade = "A"
Else If Score >= 80 Then
    Grade = "B"
Else
    Grade = "C"
End If
Print Grade
B
Common mistake: forgetting Then or End If. The parser reports the block boundary.

14. Ascending and descending For

For evaluates both bounds once, includes the final bound, and steps by one.

For Index = 1 To 3
    Print Index;
End For
Print
For Index = 3 Down To 1
    Print Index;
End For
Print
123
321
Common mistake: adding your own counter increment. SMILE already changes it once per iteration.

15. Do / Loop Until

Do is post-tested, so the body runs at least once. Omit Until for an intentional infinite loop containing Exit Do.

Tally = 0
Do
    Tally = Tally + 1
Loop Until Tally = 3
Print Tally

Output: 3.

Common mistake: expecting zero iterations when the condition starts true. Do checks only after its body.
Back to top

16. Exit For, Exit Do, and End Program

Typed exits find the nearest surrounding loop of the named kind. End Program ends the whole program—even from a routine.

For Outer = 1 To 3
    Do
        Print Outer
        Exit For
    Loop
End For
End Program
Print "unreachable"
Common mistake: using Return to end the program. Return exits one routine; End Program exits everything.

17. Sub, ByVal, and Call

Pattern: Sub Name([ByVal] P As Type) ... End Sub, called by Call Name(argument). Every parameter is ByVal.

Option Explicit
Dim Score As Number
Score = 10
Call AddFive(Score)
Print Score
End Program
Sub AddFive(ByVal Score As Number)
    Score = Score + 5
    Print Score
End Sub
15
10
Common mistake: expecting AddFive to change the caller. ByVal gives the Sub an independent value.

18. Function and Return

A Function has an exact return type and is called inside an expression. Every normal path must return.

Print Calculate(8, 3, "+")
Print Calculate(8, 3, "-")
End Program
Function Calculate(LeftValue As Number, RightValue As Number, Operation As Text) As Number
    If Operation = "+" Then
        Return LeftValue + RightValue
    Else
        Return LeftValue - RightValue
    End If
End Function
11
5
Common mistake: Call Calculate(...). Call is for a Sub; use a Function where its result is needed.

19. Global scope, local scope, shadowing, recursion

Top-level variables are global. Parameters and local Dim variables belong to one call frame and are fresh for every call. A local may shadow a same-named global.

Dim Score As Number
Score = 10
Call DemonstrateScope(5)
Print Score
End Program
Sub DemonstrateScope(Score As Number)
    Dim Doubled As Number
    Doubled = Score * 2
    Print Doubled
End Sub
10
10
Common mistake: assuming a local survives the next call. Each invocation starts with fresh local defaults.

20. Select Case

Select evaluates its selector once, checks constant cases in order, and runs the first match. Case Else is optional and last.

Command = "Defend"
Select Case Command
    Case "Attack"
        Print "attack"
    Case "Defend"
        Print "defend"
    Case Else
        Print "unknown"
End Select
defend
Common mistake: using a variable as a Case value. A Case must be a compile-time constant of the exact selector type. Keep the first Case directly after the Select header; the authoritative compiler rejects an intervening blank source item.

21. Fixed one-dimensional arrays

Pattern: Dim Names[element-count] As Text. Indexes start at zero.

Option Explicit
Const PlayerTotal = 3
Dim Scores[PlayerTotal] As Number
Dim Index As Number
Scores[0] = 75
Scores[1] = 88
Scores[2] = 92
For Index = 0 To PlayerTotal - 1
    Print Index; ": "; Scores[Index]
End For
0: 75
1: 88
2: 92
Common mistake: using index 3 in a three-cell array. Its valid indexes are 0, 1, and 2.

22. Array defaults and bounds

Number cells start at 0, Boolean cells at False, and Text cells at empty Text. A known invalid index is a compile error. A dynamic invalid index fails before memory access.

Dim Values[2] As Number
Dim Flags[2] As Boolean
Dim Words[2] As Text
Print Values[0]; Flags[0]; "["; Words[0]; "]"

Output: 0False[].

23. JavaScript versus Node.js

JavaScript is the language. Node.js is the runtime used to execute generated console programs. That is why the UI says JavaScript (Node.js).

  • Stable target ID: javascript
  • Primary file: Program.js
  • Run command: node Program.js
  • Dependencies: none—no npm package, module, or TypeScript layer

Use a current supported Node.js LTS release.

26. Diagnostics and troubleshooting

ProblemWhat to check
Unknown nameSpelling, declaration order, and Option Explicit
Wrong argumentExact count, position, and scalar type
Function may not returnEvery normal path needs a matching Return value
Array boundsUse indexes 0 through count minus one
Toolchain unavailableGeneration still works; install only the compiler/runtime you want to run

Read the first diagnostic, fix it, and compile again. Later errors can be side effects of the first malformed block.

Do not “fix” an error with legacy syntax. LET, SET, old INPUT, WHILE, raw Print templates, and alternate comments are unsupported.

28. Cumulative Core BASIC 2 program

This program combines declarations, arrays, routines, selection, and output. The larger checked-in examples/language.smile is packaged beside Desktop.

Option Explicit
Const PlayerTotal = 3
Dim Names[PlayerTotal] As Text
Dim Scores[PlayerTotal] As Number
Dim Index As Number
Names[0] = "Alyssa"
Names[1] = "Borin"
Names[2] = "Cyra"
Scores[0] = 75
Scores[1] = 88
Scores[2] = 92
Call AddBonus(1, 5)
For Index = 0 To PlayerTotal - 1
    Call ShowPlayer(Index)
End For
Select Case BestScore()
    Case 93
        Print "Top score confirmed"
    Case Else
        Print "Check the scores"
End Select
End Program
Sub AddBonus(Index As Number, Amount As Number)
    Scores[Index] = Scores[Index] + Amount
End Sub
Sub ShowPlayer(Index As Number)
    Print Names[Index]; ": "; Scores[Index]
End Sub
Function BestScore() As Number
    Dim Position As Number
    Dim Best As Number
    For Position = 0 To PlayerTotal - 1
        If Scores[Position] > Best Then
            Best = Scores[Position]
        End If
    End For
    Return Best
End Function
Alyssa: 75
Borin: 93
Cyra: 92
Top score confirmed

29. Quick grammar

item       := Option Explicit | Dim | Const | Sub | Function | statement
parameter  := [ByVal] name As (Number | Boolean | Text)
statement  := assignment | Call | Return | Print | If | Select | For | Do | Exit | End Program
array      := Dim name[constant-count] As scalar-type
call       := name(argument-list)
select     := Select Case expression · Case constant · [Case Else] · End Select

Parentheses are required for routine declarations and calls, including zero arguments. Square brackets are for the one array dimension and its index.

31. Intentionally excluded and deferred

Small is a feature. This milestone does not implement console Input, ByRef, Optional/ParamArray/named arguments, dynamic or multidimensional arrays, array parameters/returns, Enum, Type, Module, Import, classes, OOP, files/data, timing/randomness, graphics, games, media, or audio.

There is no TypeScript or npm layer, no hidden legacy mode, and no eleventh target. Console Input requires a separate authority-first design.

Documentation for a future idea is not implementation. If it is in this list, the compiler correctly rejects it today.

32. Friendly compiler glossary

Lexer
Finds words, numbers, strings, punctuation, and comments.
Parser
Checks how tokens are arranged and builds a syntax tree.
Binder
Connects each name to a declaration and checks exact types and scopes.
Bound program
The shared, already-checked meaning consumed by evaluation and generation.
Evaluator
Runs that meaning directly and serves as the expected-output oracle.
Transpiler
Translates source in one language into source in another.
Generator
The target-specific writer that produces readable C#, Python, COBOL, and so on.
Toolchain
The destination compiler or runtime that builds and runs generated files.
Scope
The part of a program where a name refers to a declaration.
Call frame
Fresh parameters and local storage for one routine invocation.

You now have the vocabulary to read a diagnostic, inspect generated code, and explain the journey from one SMILE line to ten real targets.
