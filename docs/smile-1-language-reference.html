1. Welcome to SMILE

SMILE is a beginner-first programming language. Its name—Simple Modern and Intuitive Language for Everyone—is a promise: the language stays small enough to understand while teaching real ideas such as types, functions, recursion, and arrays.

Your first program
Print "Hello, world!"

Output:

Hello, world!

2. The learning mission

You write one SMILE program. The compiler can show the same idea in ten destinations. A loop is still a loop and a function is still a function, but you learn how each community normally writes it.

Read

Start with short, case-insensitive BASIC-like source.

Compare

Open C#, JavaScript (Node.js), Python, COBOL, or another target pane.

Experiment

Change the source and watch every generated program change.

Generated code is teaching material. SMILE prefers ordinary destination constructs over a hidden runtime.

3. The compilation journey

The lexer recognizes words and symbols. The parser checks their arrangement. The binder connects names to typed declarations. The evaluator can run the bound meaning, while a generator translates it.

4. Desktop and command line

Desktop

Open a .smile file, choose a target in a pane, then use Build & Run when that toolchain is installed. Work happens asynchronously, so the editor stays responsive. Use Edit → Format SMILE or Ctrl+K, Ctrl+D to format the source as one undoable edit. Ctrl+F finds text and Ctrl+G goes to a line.

CLI

dotnet run --project src\SMILE.Cli -- examples\core-basic-2-canonical.smile --target python --run
dotnet run --project src\SMILE.Cli -- examples\core-basic-2-canonical.smile --target all
dotnet run --project src\SMILE.Cli -- examples\language.smile --format
dotnet run --project src\SMILE.Cli -- examples\language.smile --check

The syntax-aware formatter preserves Text, comments, identifiers, order, and meaning; invalid source is left untouched. Live transpilation never rewrites source. The stable target ID for JavaScript (Node.js) is javascript. Diagnostics include a code, line, column, and a plain-language message.

5. Source layout, comments, and names

Statements normally end at a newline. Keywords and identifiers ignore case, so Score and score are the same name. An apostrophe starts a comment.

Smallest example

' A full-line comment
Score = 10  ' An end-of-line comment
Print score

Output: 10

Common mistake

// not a SMILE comment

Use an apostrophe instead. Alternate comment markers are rejected.

Pattern: identifier = expression. A name begins with a Unicode letter or underscore and continues with letters, decimal digits, or underscores.

Back to top

5A. Formatting logical paragraphs

Formatting is an explicit teaching aid, not a hidden compilation step. It uses four-space block indentation, keeps related declarations and statements together, separates logical phases with one blank line, preserves Text and apostrophe comments exactly, and ends the file with one newline. Invalid source is never guessed at or rewritten.

Before

Option Explicit

Dim Score As Number
Score = 0
For Score = 1 To 3
Print Score
End For

After

Option Explicit

Dim Score As Number

Score = 0

For Score = 1 To 3
    Print Score
End For

The result is idempotent: formatting it again makes no change. Very long legal Call statements may wrap inside their parentheses; Text and comments are never reflowed.

7. Variables, Dim, and Const

Pattern: Name = expression, Dim Name As Type, or Const Name = constant-expression.

Const Bonus = 5
Dim Score As Number
Name = "Sin"
Score = 10 + Bonus
Print Name; ": "; Score

First assignment can create a variable when Option Explicit is absent. Dim creates typed default storage. Const is compile-time and immutable.

Common mistake: assigning Bonus = 6. Constants cannot change. Put changing data in a variable declared by Dim.
Back to top

8. Option Explicit

Pattern: Option Explicit once, as the first nonblank, noncomment item. It turns misspelled or undeclared variable names into errors.

Option Explicit
Dim Score As Number
Score = 100
Print Score
Common mistake: writing Scroe = 100 without a declaration. Correct the spelling or add the intended Dim. The directive produces no runtime code.

9. Arithmetic and precedence

Unary -; then * / Mod; then + -; then comparisons; then And; then Or. Parentheses make intent explicit. Division truncates toward zero.

Print 2 + 3 * 4
Print (2 + 3) * 4
Print -7 / 2
Print -7 Mod 2

20
-3
-1
Common mistake: expecting a decimal answer from 7 / 2. Number is a whole-number type; the result is 3.

10. Text and concatenation

Pattern: TextExpression + TextExpression. A doubled quote inside a literal becomes one quote.

First = "Simple"
Last = "Everyone"
Print First + " Modern and Intuitive Language for " + Last
Print "She said ""Hi""."
Common mistake: "Score=" + 10. Types are exact. Print unlike types as separate expressions: Print "Score="; 10.
Back to top

11. Comparisons and Boolean logic

Number supports ordering. Like-typed values support = and <>. Not, And, and Or work on Boolean. And/Or short-circuit.

Age = 14
HasPermission = True
CanEnter = Age >= 13 And HasPermission
Print CanEnter

Output: True.

Common mistake: If Score Then. A Number is not a condition. Write If Score > 0 Then.

12. Print

Pattern: Print [expression {; expression} [;]]. Print inserts no spaces. A trailing semicolon keeps the cursor on the same line.

Print "A"; 1; True
Print "loading";
Print "."
Print
A1True
loading.
Common mistake: Print Hello prints the variable Hello. For literal text, write Print "Hello".

13. If / Else If / Else

The first true clause runs. Else is the fallback.

Score = 87
If Score >= 90 Then
    Grade = "A"
Else If Score >= 80 Then
    Grade = "B"
Else
    Grade = "C"
End If
Print Grade
B
Common mistake: forgetting Then or End If. The parser reports the block boundary.

14. Ascending and descending For

For evaluates both bounds once, includes the final bound, and steps by one.

For Index = 1 To 3
    Print Index;
End For
Print
For Index = 3 Down To 1
    Print Index;
End For
Print
123
321
Common mistake: adding your own counter increment. SMILE already changes it once per iteration.

15. Do / Loop Until

Do is post-tested, so the body runs at least once. Omit Until for an intentional infinite loop containing Exit Do.

Tally = 0
Do
    Tally = Tally + 1
Loop Until Tally = 3
Print Tally

Output: 3.

Common mistake: expecting zero iterations when the condition starts true. Do checks only after its body.
Back to top

16. Exit For, Exit Do, and End Program

Typed exits find the nearest surrounding loop of the named kind. End Program ends the whole program—even from a routine.

For Outer = 1 To 3
    Do
        Print Outer
        Exit For
    Loop
End For
End Program
Print "unreachable"
Common mistake: using Return to end the program. Return exits one routine; End Program exits everything.

17. Sub, ByVal, and Call

Pattern: Sub Name([ByVal] P As Type) ... End Sub, called by Call Name(argument). Every parameter is ByVal.

Option Explicit
Dim Score As Number
Score = 10
Call AddFive(Score)
Print Score
End Program
Sub AddFive(ByVal Score As Number)
    Score = Score + 5
    Print Score
End Sub
15
10
Common mistake: expecting AddFive to change the caller. ByVal gives the Sub an independent value.

18. Function and Return

A Function has an exact return type and is called inside an expression. Every normal path must return.

Print Calculate(8, 3, "+")
Print Calculate(8, 3, "-")
End Program
Function Calculate(LeftValue As Number, RightValue As Number, Operation As Text) As Number
    If Operation = "+" Then
        Return LeftValue + RightValue
    Else
        Return LeftValue - RightValue
    End If
End Function
11
5
Common mistake: Call Calculate(...). Call is for a Sub; use a Function where its result is needed.

19. Global scope, local scope, shadowing, recursion

Top-level variables are global. Parameters and local Dim variables belong to one call frame and are fresh for every call. A local may shadow a same-named global.

Dim Score As Number
Score = 10
Call DemonstrateScope(5)
Print Score
End Program
Sub DemonstrateScope(Score As Number)
    Dim Doubled As Number
    Doubled = Score * 2
    Print Doubled
End Sub
10
10
Common mistake: assuming a local survives the next call. Each invocation starts with fresh local defaults.

20. Select Case

Select evaluates its selector once, checks constant cases in order, and runs the first match. Case Else is optional and last.

Command = "Defend"
Select Case Command
    Case "Attack"
        Print "attack"
    Case "Defend"
        Print "defend"
    Case Else
        Print "unknown"
End Select
defend
Common mistake: using a variable as a Case value. A Case must be a compile-time constant of the exact selector type. Keep the first Case directly after the Select header; the authoritative compiler rejects an intervening blank source item.

21. Fixed one- and two-dimensional arrays

Patterns: Dim Names[element-count] As Text and Dim Board[width, height] As Text. Indexes start at zero; game boards conventionally use [X, Y].

Option Explicit
Const PlayerTotal = 3
Dim Scores[PlayerTotal] As Number
Dim Index As Number
Scores[0] = 75
Scores[1] = 88
Scores[2] = 92
For Index = 0 To PlayerTotal - 1
    Print Index; ": "; Scores[Index]
End For
0: 75
1: 88
2: 92

A small board

Option Explicit
Const Width = 4
Const Height = 3
Dim Board[Width, Height] As Text
Board[2, 1] = "@"
Print Board[2, 1]
@
Common mistake: using index 3 in a three-cell dimension. Its valid indexes are 0, 1, and 2. A read or write must supply exactly the declared number of indexes.

22. Array defaults, order, and bounds

Number cells start at 0, Boolean cells at False, and Text cells at empty Text. A known invalid index is a compile error. A dynamic invalid index fails with SMILER1210 before memory access. For Board[X, Y] = Value, X and Y each evaluate once, left to right; both are checked before Value runs.

Dim Values[2, 2] As Number
Dim Flags[2, 2] As Boolean
Dim Words[2, 2] As Text
Print Values[0, 1]; Flags[0, 1]; "["; Words[0, 1]; "]"

Output: 0False[]. Every routine call receives fresh local arrays, including recursive calls.

23. Get Key and the key table

Get Key KeyCode polls once without waiting, without echo, and without requiring Enter. It stores KEY_NONE when no event is ready. An ANSI arrow sequence counts as one event; other ordinary events become KEY_OTHER.

ConstantValueMeaning
KEY_NONE0No event
KEY_W, KEY_A, KEY_S, KEY_D1, 2, 3, 4Letter controls, either case
KEY_UP, KEY_DOWN, KEY_LEFT, KEY_RIGHT10, 11, 12, 13Arrow controls
KEY_ENTER, KEY_ESCAPE, KEY_SPACE14, 15, 16Start, leave, action
KEY_1, KEY_2, KEY_OTHER, KEY_3, KEY_TAB, KEY_417, 18, 19, 20, 21, 22Number/menu and other keys
Option Explicit
Dim KeyCode As Number
Get Key KeyCode
If KeyCode = KEY_W Or KeyCode = KEY_UP Then
    Print "move up"
End If

24. Clear Screen, Wait, and Timer

Clear Screen erases the visible attached console, homes the cursor, and does not launch a shell. It safely does nothing when output is redirected. Wait Duration Milliseconds uses a non-busy delay; negative duration acts like zero and values above 4,294,967,295 clamp to that maximum. Timer() returns monotonic elapsed milliseconds whose starting epoch is intentionally unspecified.

Option Explicit
Dim StartedAt As Number
Clear Screen
StartedAt = Timer()
Wait 40 Milliseconds
Print Timer() >= StartedAt

Node.js Wait is Promise-based so its event loop remains responsive. The evaluator uses virtual time during deterministic tests instead of making the test sleep.

25. Random, Abs, Min, and Max

Random Result From Lower To Upper stores an inclusive whole Number. Bounds run once from left to right. Equal bounds always produce that value. When Lower is greater than Upper, SMILE stores Lower without consuming randomness. Native random sequences intentionally differ across destinations.

Option Explicit
Dim Roll As Number
Random Roll From 6 To 6
Print Roll
Print Abs(-5); " "; Min(8, 3); " "; Max(8, 3)
6
5 3 8

Abs, Min, and Max take Number arguments and return Number. At the signed minimum extreme, the evaluator reports overflow while generated targets keep the documented native-overflow policy.

26. Three complete terminal games

Trail Runner

text-snake.smile uses a roomy 60-by-17 board, starts with Enter, steers with W/A/S/D or arrows, grows after collecting food, scores, collides, restarts, and exits with Escape.

Lantern Maze

text-maze-muncher.smile uses a 59-by-17 maze with pellets, four independently moving shadows, lives, win/loss flow, and bounded placement.

27. The terminal game loop, main first, and cleanup

A responsive text game polls one event, updates state when its timer says it is time, redraws only when that state changes, waits briefly, and repeats. The checked-in games prepare each complete row before clearing so the next frame can be printed promptly instead of exposing a slowly rebuilt blank screen. The connectors below are straight or right-angle only.

Main-first destinations put the learner entry body before user routines and compiler helpers. JavaScript (Node.js) creates async main only when console behavior needs it; Python remains direct top-level code. Raw-input targets restore any changed mode on normal completion and normal error cleanup. Returning to the launcher and accepting another key proves cleanup in the interactive matrix.

28. JavaScript versus Node.js

JavaScript is the language. Node.js is the runtime used to execute generated console programs. That is why the UI says JavaScript (Node.js).

  • Stable target ID: javascript
  • Primary file: Program.js
  • Run command: node Program.js
  • Dependencies: none—no npm package, module, or TypeScript layer

Interactive output uses a raw key queue and Promise delay. Its async main and finally cleanup appear only when needed. Use a current supported Node.js LTS release.

30. Representative generated code

For Function Double(Value As Number) As Number, SMILE emits ordinary target routines. On conventional compiled targets, the learner entry body appears first, followed by user routines and then only required helpers. Imports, declarations, entry code, routines, and unavoidable support are semantic sections; ordinary targets use one blank line between sections, while Python uses its normal two blank lines before top-level definitions.

Dense output removed

Console.Write("Score: ");
Console.Write(Score);
Console.WriteLine();

Current C# output

Console.WriteLine($"Score: {Score}");

The combined statement preserves left-to-right, exactly-once evaluation. Equivalent target-native forms are used for JavaScript (Node.js), Java, Swift, Python, C, Objective-C, and C++; MASM and COBOL keep the small typed sequences their native output models require.

C#

private static long Double(long Value)
{
    return Value * 2;
}

JavaScript (Node.js)

function Double(Value) {
    return Value * 2n;
}

Python

def Double(Value):
    return Value * 2

COBOL

PROGRAM-ID. STUDENT-Double IS RECURSIVE.
PROCEDURE DIVISION USING ...
    COMPUTE SMILE-RETURN-VALUE = ...

MASM x64

_smile_Double PROC
    push rbp
    mov rbp, rsp
    ...
    ret
_smile_Double ENDP

Main-first order in C

int main(void) { Teach(); return 0; }
static void Teach(void) { /* learner routine */ }
static size_t smile_index(...) { /* required helper */ }

Names may be mapped to avoid target keywords. Helpers appear only for a real semantic need, such as bounds checks, C Text concatenation, or raw terminal polling where the target has no direct high-level operation.

31. Diagnostics and troubleshooting

ProblemWhat to check
Unknown nameSpelling, declaration order, and Option Explicit
Wrong argumentExact count, position, and scalar type
Function may not returnEvery normal path needs a matching Return value
Array boundsUse indexes 0 through each dimension's count minus one
Toolchain unavailableGeneration still works; install only the compiler/runtime you want to run

Read the first diagnostic, fix it, and compile again. Later errors can be side effects of the first malformed block.

Do not “fix” an error with legacy syntax. LET, SET, old INPUT, WHILE, raw Print templates, and alternate comments are unsupported.

33. Cumulative Core BASIC 2.1 program

This program combines declarations, arrays, routines, selection, and output. The larger checked-in examples/language.smile also demonstrates text-game primitives and is packaged beside Desktop.

Option Explicit
Const PlayerTotal = 3
Dim Names[PlayerTotal] As Text
Dim Scores[PlayerTotal] As Number
Dim Index As Number
Names[0] = "Alyssa"
Names[1] = "Borin"
Names[2] = "Cyra"
Scores[0] = 75
Scores[1] = 88
Scores[2] = 92
Call AddBonus(1, 5)
For Index = 0 To PlayerTotal - 1
    Call ShowPlayer(Index)
End For
Select Case BestScore()
    Case 93
        Print "Top score confirmed"
    Case Else
        Print "Check the scores"
End Select
End Program
Sub AddBonus(Index As Number, Amount As Number)
    Scores[Index] = Scores[Index] + Amount
End Sub
Sub ShowPlayer(Index As Number)
    Print Names[Index]; ": "; Scores[Index]
End Sub
Function BestScore() As Number
    Dim Position As Number
    Dim Best As Number
    For Position = 0 To PlayerTotal - 1
        If Scores[Position] > Best Then
            Best = Scores[Position]
        End If
    End For
    Return Best
End Function
Alyssa: 75
Borin: 93
Cyra: 92
Top score confirmed

34. Quick grammar

item       := Option Explicit | Dim | Const | Sub | Function | statement
parameter  := [ByVal] name As (Number | Boolean | Text)
statement  := assignment | Call | Return | Print | If | Select | For | Do | Exit
            | Get Key name | Clear Screen | Wait expression Milliseconds
            | Random name From expression To expression | End Program
array      := Dim name[constant-count [, constant-count]] As scalar-type
access     := name[expression [, expression]]
builtin    := Timer() | Abs(expression) | Min(expression, expression) | Max(expression, expression)
call       := name(argument-list)
select     := Select Case expression · Case constant · [Case Else] · End Select

Parentheses are required for routine declarations and calls, including zero arguments. Square brackets contain exactly one index for rank one or two indexes for rank two.

36. Intentionally excluded and deferred

Small is a feature. This milestone does not implement console Input, held-key or pointer queries, cursor-position statements, ByRef, Optional/ParamArray/named arguments, dynamic or rank-three arrays, array parameters/returns, Enum, Type, Module, Import, classes, OOP, files/data, graphics, media, or audio.

There is no TypeScript or npm layer, no hidden legacy mode, and no eleventh target. Console Input requires a separate authority-first design.

Documentation for a future idea is not implementation. If it is in this list, the compiler correctly rejects it today.

37. Friendly compiler glossary

Lexer
Finds words, numbers, strings, punctuation, and comments.
Parser
Checks how tokens are arranged and builds a syntax tree.
Binder
Connects each name to a declaration and checks exact types and scopes.
Bound program
The shared, already-checked meaning consumed by evaluation and generation.
Feature inventory
The list of operations a program actually uses, so generators omit unrelated support.
Evaluator host
An injectable source of keys, time, screen frames, waits, and random values for deterministic tests.
Transpiler
Translates source in one language into source in another.
Generator
The target-specific writer that produces readable C#, Python, COBOL, and so on.
Toolchain
The destination compiler or runtime that builds and runs generated files.
Scope
The part of a program where a name refers to a declaration.
Call frame
Fresh parameters and local storage for one routine invocation.

You now have the vocabulary to read a diagnostic, inspect generated code, and explain the journey from one SMILE line to ten real targets.
